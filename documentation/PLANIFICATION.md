# PLANIFICATION
Approches choisies pour créer le porfolio.
## Données 
- Base de donnée externe ( [Airtable](https://www.airtable.com/) )

## Animations
Dépendant de la situation, approches choisies :
- CSS pur (Scroll-driven and hover animations)
- GSAP (animations de base + animations de scroll)

### Éléments à animer :

Effet visuel (peut changer) :
- **VISUAL FX** : VHS sur toute la page

--- 

Animations Idle :
- **Infinite text wheel** : scroll vers la gauche à l'infini, se répète

Animations on hover :
- **Header navbar titles** : changement de couleur
- **Hero button 01** : changement de couleur de background de jaune à noir avec un border jaune
- **Hero button 02** : Highlight du contour
- **Carte page "projets"** : highlight de la carte 
1.   *Contour* : Passe de blanc à jaune
2.   *Grille halftone* : vient prendre la surface de la carte
3.   *Background image* : scroll vers la gauche lentement 
4.   *Texte* : Resize du texte

- **Carte page "projets" ouverte** : highlight de la carte
1.   *Close button* : S'attache et suit la souris

- **Cartes page "à propos"** : Highlight du background
- **Liens** : Changements de couleur

Animations on scroll : 
- **Parallax effect with project page** : Hero reste immobile, page projet monte vers le haut
